# 故障排查

## Muse 的页面没进我的 `Muse` 空间

**这不是故障，是预期行为**：任务在专属任务窗口里执行，扩展看不见空间、也不会按空间归置页面；你在 Ego 里切换空间，任务窗口不动。隔离靠的是窗口边界——任务窗口里只有任务页面，你的页面在你的窗口里，两边本来就不混。空间只是你自己归置窗口时的辨认工具，进不进都不影响使用。

## Muse 操作到了我自己的页面

**原因**：通常发生在让 Muse 在你已有的窗口里继续一个任务时——它操作的始终是任务所在的窗口；如果任务被带进了你的窗口，就会动到你的标签。

**处理**：让 Muse 停下，把任务回到它自己的任务窗口里再继续；并在约定里写明只动任务窗口内的页面（见模板）。

## Muse 说找不到/连不上我的浏览器

逐项检查：

1. 浏览器开着吗？扩展只在浏览器运行时工作。
2. 扩展装在**当前档案**里吗？扩展是档案级安装，换了档案等于没装。
3. 扩展里登录的 Meta 账号，和你在 Muse 里用的是同一个吗？
4. 在 Muse 里发起浏览器任务时，选的是"设备浏览器"而不是云浏览器吗？

## `Muse` 空间不见了

**正常现象**，不是故障：空间随标签全关、浏览器重启或升级消亡。在 Ego 里按名字 `Muse` 再打开/新建一个同名空间即可，后续约定不变。不要去找"恢复空间"的设置，没有那种东西。

## 页面读不全 / 评论只读到一部分

- 长列表页面需要滚动加载：让 Muse 分段滚动、逐段读取，而不是一次抓取。
- 某些站点对自动化读取有限制（如只返回部分回复）；先确认人工打开时页面本身是否完整，再判断是不是通道问题。

## 扩展装不上 / 商店里搜到好几个

只认发行方为 **Meta** 的 **Muse from Meta**。仿冒扩展是真实存在的风险，装错等于把页面数据送给陌生人。

## 需要 Muse 接管我正在看的页面时

先让 Muse 在它自己的专属任务窗口里把目标页面新开一个标签，并向你报明"窗口里应该看到的标签标题和地址"，你核对无误再让它动手——多窗口、多标签时这一步能避免它认错页面。
